1System Overview

Three distinct badge types serve different roles. They are not the same — one is permanently rare, one changes monthly, one builds over time. Each looks visually different so users and other collectors can tell them apart instantly.

#Badge TypeHow earnedExpires?Visual shape
1First Start BadgesManually assigned by the Scorred team to founding members and earliest users. No XP required.Never — permanent foreverRounded square with emoji
2Monthly Activity BadgesAuto-awarded at end of each month to top performer per category (most posts, comments, shares, etc.)Label is current month's title. Past ones archived in trophy case.Rounded square with emoji
3XP / Season Badges(a) Rank badge — from lifetime XP milestones. (b) Leaderboard badge — from weekly/monthly league placements.Rank badge updates as you level up. Season (league) badges are permanent once earned.Circle (metallic finish)

2Badge Display Rules — Where & How Many

New in v2 — implemented

Badge display now differs by surface. Profile and Leaderboard show the full shelf. Feed shows exactly one badge to avoid clutter. The one badge shown in the feed follows a strict priority rule (§3).

2.2 Leaderboard — Multiple badges per row

Each leaderboard entry shows the user's single feed badge (priority badge) next to their name inline. The full shelf is accessible via their profile tap.

2.3 Feed — Exactly ONE badge per post

  • Only one badge shown next to the author name in the feed. No stacking.
  • Keeps the author line clean — long badge names don't break the layout.
  • Badge is tappable → opens BadgeSheet explaining it.
  • Which badge shows follows the priority rule in §3.
Design rationale

Multiple badges next to a name in the feed creates a noisy, badge-collector-game feel — not what we want. One badge is a clear signal of that person's identity or current achievement. The full collection lives on the profile.

3Feed Badge Priority Rule

When a user has multiple badge types, the feed shows one according to this priority order:

PriorityBadge typeWhy first
1stFirst Start Badge (Founding Member / Early Believer / Pioneer)These are the rarest badges — permanently assigned by the team. They signal who believed earliest and should always be the primary identity marker in the feed.
2ndMonthly Activity Badge (Top Showcaser, Comment King, etc.)Timely and relevant — shows what the person is doing right now. If they have no permanent badge, this is their current identity signal.
3rdRank Badge (Rookie, Hunter, Collector, etc.)Everyone has one. Shows for users who have no first-start or monthly badge — so no author ever appears badge-less.
Key rule

If a user has a First Start badge → always shows that in feed, even if they also have monthly and season badges. The permanent badge takes precedence. This makes Founding Members and Pioneers instantly identifiable at a glance throughout the app.

4Clickable Badges — BadgeSheet

New in v2 — implemented

Every badge across the entire app is tappable. Tapping any badge opens a BadgeSheet — a bottom sheet popup that explains exactly what the badge is and how it was earned.

BadgeSheet contents

  • Badge icon (large, 76px) — emoji square for First Start/Monthly, metallic circle for Season
  • Badge type label — "Permanent badge" / "Monthly badge" / "Rank badge" / "Season badge" (10px all-caps)
  • Badge name (22px bold) — e.g. "Founding Member"
  • Description (14px) — plain English explanation of how it's earned and whether it expires
  • Got it button — closes the sheet

Where badges are tappable

  • Feed — the single feed badge pill next to the author name
  • Profile header — each badge in the BadgeShelf individually
  • Leaderboard — the feed badge pill shown next to each user's name
  • Trophy Case — each badge row/card in the full badge list
