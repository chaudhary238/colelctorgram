1System Overview

Two distinct badge types serve different roles. They are not the same — one is permanently rare, one builds over lifetime XP. Each looks visually different so users and other collectors can tell them apart instantly.

  • Only one badge shown next to the author name in the feed. No stacking.
  • Keeps the author line clean — long badge names don't break the layout.
  • Badge is tappable → opens BadgeSheet explaining it.
  • Which badge shows follows the priority rule in §3.
Design rationale

Multiple badges next to a name in the feed creates a noisy, badge-collector-game feel — not what we want. One badge is a clear signal of that person's identity or current achievement. The full collection lives on the profile.

3Feed Badge Priority Rule

When a user has multiple badge types, the feed shows one according to this priority order:

PriorityBadge typeWhy first
1stFirst Start Badge (Founding Member / Early Believer / Pioneer)These are the rarest badges — permanently assigned by the team. They signal who believed earliest and should always be the primary identity marker in the feed.
2ndRank Badge (Rookie, Hunter, Collector, etc.)Everyone has one. Universal fallback so no author is ever badge-less in the feed.
Key rule

If a user has a First Start badge → always shows that in feed, even if they also have season badges. The permanent badge takes precedence. This makes Founding Members, Early Believers, and Pioneers instantly identifiable at a glance throughout the app.

4Clickable Badges — BadgeSheet

New in v2 — implemented

Every badge across the entire app is tappable. Tapping any badge opens a BadgeSheet — a bottom sheet popup that explains exactly what the badge is and how it was earned.

BadgeSheet contents

  • Badge icon (large, 76px) — emoji square for First Start, metallic circle for Season
  • Badge type label — "Permanent badge" / "Rank badge" / "Season badge" (10px all-caps)
  • Badge name (22px bold) — e.g. "Founding Member"
  • Description (14px) — plain English explanation of how it's earned and whether it expires
  • Got it button — closes the sheet

Where badges are tappable

  • Feed — the single feed badge pill next to the author name
  • Profile header — each badge in the BadgeShelf individually
  • Leaderboard — the feed badge pill shown next to each user's name
  • Trophy Case — each badge row/card in the full badge list
