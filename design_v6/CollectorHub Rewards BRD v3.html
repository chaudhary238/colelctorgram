1System Overview

Two distinct badge types serve different roles. They are not the same — one is permanently rare, one builds over lifetime XP. Each looks visually different so users and other collectors can tell them apart instantly.

#Badge TypeHow EarnedExpires?Visual Shape
1 First Start Badges Manually assigned by the CollectorHub team to founding members and earliest users. No XP required. Pioneers & Early Believers also receive a gold avatar frame on their profile. Never — permanent forever Rounded square with emoji
2 XP / Season Badges (a) Rank badge — from lifetime XP milestones. (b) Leaderboard badge — from weekly or lifetime league placements. Rank badge updates as you level up. Season (league) badges are permanent once earned. Circle (metallic finish)

2Badge Display Rules — Where & How Many

Design principle

Badge display differs by surface. Profile shows the full shelf (all badges). Feed shows exactly one badge to avoid clutter. The one badge shown in the feed follows a strict priority rule (see §3).

2.1 Profile — Full Badge Shelf

  • Shows up to 5 badges overlapping, then a "+N" overflow button.
  • Each badge is individually tappable → opens BadgeSheet explaining that specific badge.
  • "X badges →" text button navigates to full Trophy Case.
  • Order: First Start badges first → Season badges (chronological within each type).
  • Pioneers and Early Believers show a gold avatar frame around their profile picture.

2.2 Avatar Frame — Pioneers & Early Believers Only

A gold ring border is applied to the profile avatar for Pioneer and Early Believer badge holders. This is the only surface where the frame appears.

2.3 Leaderboard — Single Badge Per Row

Each leaderboard entry shows the user's priority badge (see §3) next to their name inline. The full shelf is accessible via their profile tap.

2.4 Feed — Exactly ONE Badge Per Post

  • Only one badge shown next to the author name. No stacking.
  • Keeps the author line clean — long badge names don't break the layout.
  • Badge is tappable → opens BadgeSheet.
  • Which badge shows follows the priority rule in §3.
Design rationale

Multiple badges next to a name in the feed creates a noisy, badge-collector-game feel. One badge is a clear signal of that person's identity. The full collection lives on their profile.

3Feed Badge Priority Rule

When a user has multiple badge types, the feed shows one according to this priority order:

PriorityBadge TypeRationale
1st First Start Badge
Founding Member / Early Believer / Pioneer		 The rarest badges — permanently assigned by the team. They signal who believed earliest and should always be the primary identity marker.
2nd Rank Badge
Rookie, Hunter, Collector, etc.		 Everyone has one. Universal fallback so no author is ever badge-less in the feed.
Key rule

If a user has a First Start badge → always shows that in feed, even if they also have season badges. The permanent badge takes precedence. This makes Founding Members, Early Believers, and Pioneers instantly identifiable throughout the app.

4Clickable Badges — BadgeSheet

Every badge across the entire app is tappable. Tapping any badge opens a BadgeSheet — a bottom sheet popup that explains what the badge is and how it was earned.

BadgeSheet Contents

  • Badge icon (large, 76px) — emoji square for First Start, metallic circle for Season
  • Badge type label — "Permanent badge" / "Rank badge" / "Season badge" (small caps)
  • Badge name (bold, large) — e.g. "Founding Member"
  • Description — plain English explanation of how it's earned and whether it expires
  • Got it button — closes the sheet

Surfaces Where Badges Are Tappable

  • Feed — the single feed badge pill next to the author name
  • Profile header — each badge in the BadgeShelf individually
  • Leaderboard — the feed badge pill next to each user's name
  • Trophy Case — each badge row in the full badge list

9Leaderboards

Two leaderboards are active. Monthly leaderboard has been removed.

BoardRanks ByResetsEnd-of-cycle Prize
Weekly XP earned in the current week Every Monday at midnight Top 3 earn Gold/Silver/Bronze badge + bonus XP added permanently to lifetime total
Lifetime Total XP ever accumulated Never resets Permanent ranking — no seasonal badge, reflects rank ladder position
How weekly XP flows to lifetime

Every XP point earned during the week adds to both the weekly leaderboard total and the lifetime total simultaneously. When the week resets, the weekly score returns to zero — but the lifetime total keeps everything, including any end-of-cycle bonus XP from placing in the top 3.
