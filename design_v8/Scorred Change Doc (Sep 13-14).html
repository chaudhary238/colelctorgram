Scorred — Change Doc
Sep 13–14, 2026
Compares yesterday's build to today's — today's version is the final, approved state. Covers community moderation, events, feed/market cards, messaging, and profile.

Community

FeatureTypeWhat changed
Card badgesBugRemoved reserved empty space for Private/Pending/Admin badges — public communities no longer show an awkward gap between name and member count.
DirectoryFlowYour Communities / Discover split into a segmented tab control (joined count shown in the tab label) instead of stacked sections.
FiltersFlowCategories moved into a filter sheet (same pattern as Market); added a Sort by option — Most members, Newest, Name.
Unread indicatorFlowCommunities you manage now show a red pending-count badge on the list (join requests + posts to review) without opening the community.
Join / Request buttonBugFixed-width button so "Join" / "Request to join" / "Requested" no longer shift the row.
Leave communityFlowAdded a real leave flow: plain members get a confirm dialog; a sole Admin/Mod is forced to promote a member to Admin before leaving; Admins/Mods reach Leave from Manage Community (Settings tab or Members tab), not the header.
Header layoutBugFixed overlapping/wrapped badge and meta text (Private, Posts reviewed, member/post counts) by allowing wrap instead of clipping mid-word.
Manage → MembersVisualMember rows compressed to a single-line block (matching Requests); role editor and Remove now expand only on tapping the edit icon.
Manage → role changesFlowChanging a member's role (Member/Mod/Admin) now prompts a confirm dialog first, so a mis-tap can't change or remove someone's access.
Manage stat tilesFlowMembers / Requests / To review tiles are now clickable — jump straight to that tab.

Events

FeatureTypeWhat changed
FiltersFlowCategories moved into a filter sheet; added Price (All/Free/Paid) and RSVP (All/Going/Interested) filters.
Interested markerVisual"Interested" badge/filter now shows a star icon instead of plain text or a literal asterisk.
My EventsFlowRebuilt to use the same EventCard as Upcoming/Going/Past, with live going-count and a "Hosting"/"Pending approval" tag — was a bespoke row before.
Detail iconsBugEntry, Category and Ticket link rows had the same icon — now ticket / tag / external-link respectively.
Filter sheet positionBugFixed the Events (and Community) filter sheet rendering pushed down the page instead of overlaying — switched to fixed positioning.

Feed & Market cards

FeatureTypeWhat changed
Post type ribbonsVisualReplaced heavy colored card borders and solid pill ribbons with a small rotated outline stamp (Review / Wanted / For Sale / Release) — subtler, no card border needed.
Badge paletteBugUnified the "rainbow badge" colors (author badges, status tags) into one limited semantic palette; brand red reserved for primary CTAs.
Post overlapBugReview ribbon reserves space so it never overlaps the ADMIN/role badge, Collector chip, or +Follow button; name row wraps instead of compressing.
Post actionsFlowAdded a Delete option (kebab menu) for your own posts.
Wanted / For Sale parityVisualWanted cards (feed and Market grid) now match For Sale cards exactly: removed condition/city chip row, added handle + vouch icon+count, and renamed "I have this" to "Message".
Market cardVisualAdded seller handle; replaced "Vouched by N" text with a plain vouch icon + count.
Database "add" iconBugThe "in collection" checkmark used the brand seal icon on a matching green button, making it invisible — replaced with a plain white checkmark.

Messaging

FeatureTypeWhat changed
EmojiFlowAdded an emoji picker (toggle next to the input) — was previously unavailable in chat.
Attach menuFlowRemoved "Share listing" and "Make offer" (deals/offers aren't tracked) — attach now only sends a photo.

Profile

FeatureTypeWhat changed
Other users' collectionFlowViewing someone else's profile now shows only Owned and DB Contributions — Wishlist and PO Calendar are owner-only.
Rank cardVisualOn other users' profiles, the full rank card collapsed to a single-line pill (icon + tier + inline progress bar + XP) that opens the Leaderboard — your own profile keeps the full card with "Earn points".

Onboarding

FeatureTypeWhat changed
Splash taglineFlowChanged to a "For the collectors, by the collectors" eyebrow over "Track, trade & network on the #1 collectibles platform" — removed the India-specific reference.
